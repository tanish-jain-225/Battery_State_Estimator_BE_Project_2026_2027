## 📥 How to Upload Proof Documents

1. Save the official confirmation PDF received from the journal editorial management system (e.g., ScholarOne, Editorial Manager, IEEE Author Portal).
2. Name the file clearly:
   - `docs/Paper_Proof/Review_Paper_Submission_Receipt.pdf`
   - `docs/Paper_Proof/Research_Paper_Submission_Receipt.pdf`
3. Update the Submission Log Registry table above with the Paper ID and date.
4. Commit the proof files to the repository.
