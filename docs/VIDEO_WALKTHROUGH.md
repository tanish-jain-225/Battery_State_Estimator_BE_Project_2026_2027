## 🎬 Tips for a High-Quality Video Recording

1. **Prerequisites Checklist**:
   * Make sure your database is running or in-memory fallback is active.
   * Run `python software/visualiser/training/train_rc.py` and `python hardware/train_classifier.py` beforehand so all model files (`model_rc.pkl`, `esn_classifier_weights.h`) are built and up to date.
   * Open the dashboard browser (`http://localhost:5000`) and the C simulator code in split windows before recording.
2. **Narration Pacing**:
   * The total script is approximately **620 words**. Speaking at a moderate rate of 130 words per minute will leave you with around 45–50 seconds of buffer time to perform screen actions (clicking buttons, scrolling code) smoothly without rushing.
   * Pause for 1–2 seconds when transitioning between sections or after initiating a compilation to let the screen action catch up.
3. **Screen Resolution**:
   * Set your screen resolution to `1920x1080` (1080p) and increase the font size in VS Code (using `Ctrl +` or `Cmd +`) so the evaluators can easily read the code lines and variable names on screen.
